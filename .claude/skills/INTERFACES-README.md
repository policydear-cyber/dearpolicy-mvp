# Interface design skills (vendored)

The skills `better-interface`, `better-accessibility`, `better-colors`, `better-layout`,
`better-typography`, `better-ui`, `better-writing`, `interface-review`, `build-design`,
`variant`, `break`, `state-machine` and `explain-interface` are copied unchanged from
https://github.com/jakubkrehel/skills at commit `6c2120103600407a1a9986afd834e73144ef8998`
(plugin version 1.20.0), by Jakub Krehel, under the MIT licence in `INTERFACES-LICENSE`.

Left out on purpose: `afk`. It runs unattended for hours, explores new ideas and commits on its
own branch, which conflicts with this project's rules (no new features until the launch
checklist passes; the owner decides scope, merges and deploys).

To update: copy the newer `skills/<name>/` folders over these, keep `afk` out, record the new
commit above and re-read every changed file before committing. Do not edit the vendored files
in place; put DearPolicy-specific rules in `CLAUDE.md`, `docs/brand.md` or `docs/copy.md`.
